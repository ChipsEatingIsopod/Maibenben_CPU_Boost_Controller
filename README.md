CPU Boost Controller

A simple Windows utility for controlling Processor Performance Boost Mode through the built-in powercfg system tool.

Features
View all available Windows power plans
Select a specific power plan
View current Boost settings for:
AC power
Battery
Configure all available Boost modes:
Disabled
Enabled
Aggressive
Efficient Aggressive
Efficient Enabled
Apply settings to:
AC Power + Battery
AC Power Only
Battery Only
Restart the application as Administrator
Requirements
Windows 10 / 11
Administrator privileges for changing power settings

No additional software is required when using the compiled .exe.

Usage
Launch CPUBoostController.exe
Select a Power Scheme.
Select the desired Boost Mode.
Choose where to apply it.
Click Apply.

If administrator privileges are required, click:

Restart as Administrator

Boost Modes
Mode	Description
Disabled	Disables processor Boost/Turbo
Enabled	Standard Boost operation
Aggressive	More aggressive frequency boosting
Efficient Aggressive	Aggressive Boost with greater efficiency focus
Efficient Enabled	Boost with a focus on power efficiency
